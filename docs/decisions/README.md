# Decisions

Why the game works the way it does, for choices someone might otherwise reopen or undo. A decision is worth a file when the reason is not obvious from the code. Mechanics docs say what the rules are; these say why.

| Decision | Date |
| --- | --- |
| [Stamina is soft fatigue, not a second attack counter](stamina-is-soft-fatigue.md) | 2026-10-28 |
| [Supporter price changes apply to new purchases only](supporter-prices-new-purchases-only.md) | 2026-10-29 |
| [Era totals outlive the logs they came from](era-totals-outlive-logs.md) | 2026-11-06 |

Each file gives the decision and only the reasons that were actually recorded. If no reason was recorded, say so rather than inferring one. Don't rewrite a past decision. When one is replaced, add a new file and link it from the old one.
